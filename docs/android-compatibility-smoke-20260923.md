# Android 3× 호환성 단기 검사 — 2026-09-23

Mac의 Android 에뮬레이터에 설치된 게임 파일 **229개**를 요청한 **3× 속도에서만** 짧게 부팅하고 정해진 입력을 보냈습니다. 검사 계획에서 28개 파일을 같은 제목의 14쌍으로 묶었고, 나머지 201개 파일은 개별 검사했습니다. 개별 검사 중에도 중복 파일 두 쌍을 추가로 발견하여 총 16쌍을 비교했습니다. 검사의 목적은 검은색·흰색 부팅 화면, 충돌, 뚜렷한 진행 불가를 찾고 같은 게임 파일 중 상대적으로 나은 것을 고르는 것이었습니다. **전체 플레이, 저장·음악·화면 품질, 1× 동작은 검증하지 않았습니다.** 3× 설정은 비동기 게임 시작 직후 전달하므로 첫 아주 짧은 실행이 설정 적용 전일 가능성은 남습니다. 정지해 보이는 제목 화면이나 연결 선택창만으로는 고장으로 판정하지 않았습니다.

자동 검사에서 우선 확인이 필요했던 단독 항목 11개를 같은 3×에서 더 오래 기다리고 다른 입력으로 다시 검사했습니다. 그중 **10개에서 대상 증상이 재현**되었습니다.

| 재현된 증상 | 게임 파일 | 관찰 |
| --- | --- | --- |
| Android 앱 프로세스 충돌 (SIGSEGV) | 동전쌓기 에볼루션, 생과일 타이쿤 파이널 | 두 번의 검사에서 각각 재현. 프로세스가 종료되어 해당 순간의 Rescue 상태는 확보하지 못했습니다. |
| 게스트 실행 오류 | 치킨타이쿤, 라그나로크 바이올렛, 스도쿠 넘버홀릭, 메이플스토리 궁수편, 놈투 | 부팅 중 또는 재시작 후 오류가 재현되었습니다. 오류 원인과 수정 여부는 별도 조사 대상입니다. |
| 백그라운드 실행 오류 | 박정석 영웅탄생 | 화면은 검은 상태이고 게스트 백그라운드 스레드 오류가 다시 기록되었습니다. |
| 이 검사에서 진행하지 못한 화면 | 게임빌2010프로야구, 지크 | 각각 검은 부팅 화면과 고정된 로딩 화면이 재현되었습니다. 후자는 그림 갱신은 계속되었습니다. |

같은 11개 중 **얍은 실패로 세지 않았습니다.** 화면에 완전 종료 후 재실행하라는 안내가 표시됐고, 실제 프로세스 종료·재실행 뒤 새 게임 슬롯까지 진행했습니다. 추가 확인에서 **놈ZERO는 인증 실패 안내를 확인한 뒤 제목 화면에 도달**했습니다. **이노티아연대기2는 인증 오류 `3:001`을 표시한 뒤 종료**되어 해당 인증 경로의 진행 문제는 남아 있습니다.

같은 제목의 파일 비교에서 **놈3은 이 3× 검사에 한해 KTF 파일을 우선**합니다. KTF는 설정 화면까지 갔고, LGT는 주로 흰 화면에 머물며 진행이 의심됐습니다. 이는 예전의 일괄 LGT 우선 기록을 이 파일·검사 조건에 대해서만 바로잡는 것이며, 모든 LGT 게임이나 1× 결과에 적용하지 않습니다. 다크슬레이어2는 SKT 파일의 시작 오류가 재현됐고 KTF 파일도 로딩 화면에서 진행이 의심되어, 어느 쪽도 정상 플레이가 입증되지 않았습니다. **붕어빵 타이쿤3과 크로이센을 포함한 나머지 중복 파일은 대체로 동률이거나 판단 근거가 부족**합니다. 짧은 부팅 결과만으로 안정성 승자를 확정하지 않습니다.

게임 원본, 개별 저장 데이터와 Rescue·충돌 기록은 비공개 검사 자료로 보관하며 이 저장소에 포함하지 않습니다. 충돌로 Rescue가 생성되지 않았거나 기록 한도에 도달한 경우에는 현재 장면의 정확한 복원 지점이 확보됐다고 주장하지 않습니다. 이전의 사용자 확인 목록은 당시의 분류이며, 이 검사는 그 전체를 새로 판정한 것이 아닙니다.
