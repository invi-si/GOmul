# 참고 프로젝트와 독립 구현 범위

## 기반 프로젝트: WIE

[dlunch/wie](https://github.com/dlunch/wie)는 GOmul의 실제 기반입니다. ARM 실행, JVM, 통신사별 런타임과 API 구현의 출발점이며 원래 이력·저작권·MIT 고지를 보존합니다. GOmul은 이 기반에 Android 런처, 저장·구조 기능, 입력·타이머·그래픽·통신사 호환성 수정과 테스트를 추가했습니다.

## 비교 프로젝트: W-Feature

[movingwoo/wfeature](https://github.com/movingwoo/wfeature)의 `a621a6a56dbc6e8f5da967d23218ec750d73001c`를 구조·기능 책임 비교에 사용했습니다. 해당 프로젝트가 사용하는 기능을 모두 가져왔다는 뜻은 아닙니다. 코드나 알고리즘을 복사하지 않았으며 아래 사항을 GOmul에서 독립적으로 검증·구현했습니다.

| 비교 영역 | GOmul 결과 |
| --- | --- |
| MIDP RMS 저장 | 잘못된 범위·ID 검증, 지속되는 레코드 ID, 열기/닫기 횟수·삭제·목록 처리와 회귀 테스트 |
| 동봉 저장 데이터 | SKT `.sb`/`.db` 검증 및 최초 가져오기. 기존 저장과 삭제 표시가 있으면 덮어쓰지 않음 |
| 기기 정보 | SKT MIN/m.MIN이 설정된 에뮬레이션 기기 정보를 사용하도록 수정 |
| Canvas 입력 | 키 이름과 입력 기능 조회 지원. 기존 원시 키 매핑은 유지 |
| 오디오 | 잘못된 SMAF와 사운드폰트 초기화 실패를 처리. PCM 경로 보존 |
| 압축 파일 구조 | Android·브라우저에서 폴더 안에 들어 있는 단일 KTF 게임 루트 처리 |
| 브라우저 저장 | 게임별 로컬 백업/복원과 활성 게임 잠금, 다른 게임·기존 저장 보존 |
| CPU·게임 타이밍 | 새로운 최적화는 채택하지 않음. 기존 결정론적 검증과 타이머 의미 유지 |
| GNEX/GVM SGS | 새 VM을 구현하지 않았으며 지원을 주장하지 않음 |

API 계약은 [MIDP RecordStore](https://docs.oracle.com/javame/config/cldc/ref-impl/midp2.0/jsr118/javax/microedition/rms/RecordStore.html) 등 공개 명세를 근거로 했습니다. 참고 구현을 통신사 ABI의 권위 있는 명세로 취급하지 않습니다.

## 검증과 제한

해당 비교 작업 완료 시 Rust 테스트 307개, 브라우저 테스트 40개가 통과했습니다. Chromium·데스크톱 WebKit에서 실제 IndexedDB 복원과 제한된 게임 부팅을 확인했습니다. 이것은 전체 게임·실제 iPhone·모든 Android 기기의 인증 결과가 아닙니다. 새 성능 개선 수치를 주장하지 않습니다.

RMS 저장은 버전이 있는 메타데이터 레코드를 사용합니다. 이전 빌드에서 새 저장 형식을 읽지 못할 수 있으므로 다운그레이드 전에 백업하세요. 브라우저 백업은 일반 저장이며 Android 실행 상태 체크포인트가 아닙니다.

실험 순서와 세부 근거는 [원본 연구 기록](wfeature-comparison-20260914.md)에 보존합니다. 연구 기록의 과거 ‘미배포’·후보 상태는 기록 당시의 상태이며 현재 배포 상태는 릴리스와 변경 내역을 우선합니다.
