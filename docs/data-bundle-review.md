# Standalone Action Hero data review

The privately supplied bundle contains nine files: savedata, locdata, ranker, it0016, it0017, it0018, it0024, mk0032, and mk0033. Their names alone do not establish what they contain or a right to redistribute them. Initial inspection found structured/text-like content in locdata and opaque bytes in savedata; no complete format or rights determination has been made.

No explicit redistribution licence was supplied for these files. Therefore **none of this bundle is included** in source, Git history, release assets, or test fixtures. A future inclusion requires establishing the contents and an applicable permission covering those contents. Mere availability on a download page is not treated as a licence.

The setup tool imports users' own files and creates a private checkpoint. The phone identity is a local input, not a bundled default. This preserves the setup capability without distributing game content or personal provisioning values.
