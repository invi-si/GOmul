# 2026-09-14 공개 갱신 검증

## 반영 범위

최근 Android·브라우저·공유 런타임 수정, 테스트, 빌드 도구와 개발 기록을 기본 배포 브랜치에 통합합니다. 한국어 README·빌드·호환성·변경 내역·출처 안내를 제공합니다. 법적 라이선스와 과거 실험 기록은 원문을 보존합니다.

WIE 기반 이력을 유지합니다. W-Feature 비교에서 참고한 범위와 독립 구현 내용을 별도로 설명합니다. 게임 파일을 담은 개인용 웹 배포 ZIP은 GitHub에 올리지 않습니다.

처음 전체 Rust 테스트는 디스크 부족으로 링크 단계에서 중단됐습니다. 재생성 가능한 증분 빌드 캐시만 정리한 뒤 전체 명령을 다시 실행해 위 통과 결과를 확인했습니다. 테스트를 생략하거나 실패한 코드를 통과로 처리하지 않았습니다.

첫 TypeScript 검사는 새 작업 디렉터리에 WASM 바인딩이 아직 없어 실패했습니다. 정식 웹 빌드로 바인딩을 생성한 후 다시 통과했습니다.

## 배포와 제한

기존 0.1.0 릴리스의 APK와 한국어 설명을 갱신합니다. 최초 `v0.1.0` 태그는 이동하지 않으며 실제 갱신 소스 커밋은 릴리스 본문에 명시합니다. 개발 서명 APK이므로 스토어 배포판은 아닙니다.

이번 공개 준비에서는 사용자 AVD나 실제 휴대폰에 APK를 설치하지 않았고 새 수동 게임플레이 검증도 하지 않았습니다. 최근 별도 Chromium/WebKit 검증은 [비교 기록](wfeature-comparison-20260914.md)에 있습니다. 전체 게임의 완전 호환·iPhone 성능·새 FPS 향상을 주장하지 않습니다.

정적 파일/패턴 검사는 모든 가능한 비밀을 수학적으로 배제하는 도구가 아닙니다. 허용된 바이너리는 기존 Hello World·ARM 합성 테스트, 빌드 도구, 앱 자산·글꼴·사운드폰트입니다. 개인 저장·인증 번들·기기 스냅샷은 공개 대상에서 제외합니다.
