Rust dependency notices:
Rust-DEPENDENCIES.txt contains the locked Wasm, macOS ARM64, Android ARM64,
and Windows x64 dependency notices, including exact versioned source archive URLs.
Regenerate from the source repository with:
  python3 scripts/generate-rust-notices.py
The generator includes runtime and build dependencies. When a published crate
omits its workspace license, it retrieves the notice at the crate's recorded
upstream commit. Mozilla's MPL-2.0 text is included for the dependency that names it.

These assets and dependencies retain their respective licenses.
