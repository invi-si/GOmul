WIE Launcher

보유한 WIPI / J2ME 게임을 이 기기에 추가하고 실행하세요. 게임 파일은 포함되어 있지 않으며, 게임마다 호환성이 다릅니다.

  1. 앱 추가 / Add game지원되는 .jar 또는 .zip 게임 파일을 선택합니다.
  2. 앱 실행라이브러리에서 추가된 앱 아이콘을 누릅니다.
  3. 앱 관리오른쪽 위 메뉴에서 앱을 삭제하거나 설정을 변경합니다.
